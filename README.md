## Quickly Start
1. Download the pre-trained model weights:
   - FocusDiT Transformer: `HakimZJU/FocusDiT` from ModelScope Model Hub.
   - Mochi VAE: `mochi-1-preview/vae` from HuggingFace Model Hub.
   - Text Encoder: `google/flan-t5-xxl` from HuggingFace Model Hub.
2. Modify prompts in `infer.py` as needed.
3. Run inference:
    ```bash
    python infer.py
    ```
